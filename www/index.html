arche, compiled to WebAssembly

These arche compute programs were built with arche build --arch=wasm32 and run right here in your browser via a tiny WASI shim. Pick one and run it — its fmt output appears below.


  
  
Compute demos render their fd_write (stdout) above. The balls demo is
    a gfx (Tier 1) module: the same arche program that runs as a native window here renders into its own
    software framebuffer, driven by requestAnimationFrame and blitted to the canvas — no server
    round-trip; the world runs entirely in the page's WebAssembly sandbox.
