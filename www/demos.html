arche → WebAssembly — demo gallery

A test-only gallery of the sample arche build --arch=wasm32 programs. The public site is the app itself, full-screen; this page just makes each sample selectable so the end-to-end tests can drive it.


  
  
Compute demos render their fd_write (stdout) above. The square demo
    is a gfx (Tier 1) module: arche renders into its own software framebuffer, driven by
    requestAnimationFrame and presented to the GPU (WebGL), with ← / → keys fed back in — no
    server round-trip; the world runs entirely in the page's WebAssembly sandbox.
